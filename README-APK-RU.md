# Chatora — исходный код для Android-упаковки

Это полный исходный код веб-приложения Chatora со всеми реализованными функциями:

- вход через Google или электронную почту и пароль;
- 12 языков, включая арабский и иврит с направлением справа налево;
- личные чаты, поиск и приглашение по публичному коду пользователя;
- текстовые и голосовые сообщения;
- аудиозвонки;
- установка как PWA с иконкой Chatora.

## Самый надёжный способ получить APK

1. Опубликуйте Chatora, чтобы приложение имело постоянный HTTPS-адрес.
2. В стороннем Android/PWA-конструкторе выберите импорт по URL или упаковку PWA/TWA.
3. Укажите опубликованный адрес Chatora и используйте файлы из папки `public` для значков.
4. Разрешите приложению доступ к микрофону — он нужен голосовым сообщениям и звонкам.
5. Соберите и подпишите APK средствами выбранного конструктора.

Этот вариант сохраняет подключение к действующей базе, Google-вход, сообщения и звонки. Простое преобразование исходников в статический HTML не подходит: приложению нужны серверная часть и HTTPS.

## Если конструктор принимает исходный код

- Среда: Node.js 20+.
- Установка: `npm install` или `bun install`.
- Запуск: `npm run dev`.
- Сборка: `npm run build`.
- Публичные настройки подключения находятся в `.env.example`. Скопируйте его в `.env` и заполните значениями своего проекта.
- Никогда не добавляйте в APK `SUPABASE_SERVICE_ROLE_KEY` или другой закрытый серверный ключ.

## Сборка Android через Capacitor

1. Заполните публичные настройки в `.env`.
2. Выполните `npm run build`. Сборка подготавливает `index.html` для Android из SPA-оболочки TanStack Start.
3. При первой сборке добавьте платформу: `npx cap add android`.
4. После следующих сборок синхронизируйте веб-файлы: `npx cap sync android`.
5. Откройте проект командой `npx cap open android` и соберите APK в Android Studio.

## Важно

Схема базы находится в `supabase/migrations`. Если используется существующий опубликованный Chatora, повторно применять миграции не нужно. Google-вход в APK должен возвращать пользователя на разрешённый публичный адрес приложения.
